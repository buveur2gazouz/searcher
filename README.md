# 🛠️ Multi Tools

**Multi Tools** est un projet open source et gratuit créé par un membre de la communauté.

Le but du projet est de regrouper plusieurs petits outils utiles dans un seul programme, afin de faciliter l'apprentissage, les tests et l'utilisation de différents outils.

## ✨ Fonctionnalités

* 🛠️ Plusieurs outils réunis dans un seul programme
* 🐍 Développé en Python
* 🆓 Gratuit
* 🔓 Open Source
* 📚 Projet pensé aussi pour l'apprentissage
* 🤝 Contributions de la communauté bienvenues

## 🚀 Installation

Clone le dépôt :

git clone https://github.com/TON-PSEUDO/Multi-Tools.git

Entre dans le dossier :

cd searcher-Main

Installe les dépendances :

pip install -r requirements.txt

Puis lance le programme :

python multi_tools.py

## 🤝 Contribution

Tu peux proposer des améliorations, corriger des bugs ou ajouter de nouveaux outils.

Les contributions de la communauté sont les bienvenues !

## ⚠️ Utilisation responsable

Ce projet est destiné à l'apprentissage, au développement et à des tests autorisés.

N'utilisez pas les outils contre des systèmes, réseaux ou personnes sans autorisation.
