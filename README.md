🛠️ Multi Tools

Multi Tools est un projet open source et gratuit, créé par un membre de la communauté pour regrouper plusieurs outils dans un seul programme.

Le projet est avant tout destiné à l'apprentissage, aux tests et à la découverte de différents outils.

✨ Fonctionnalités
🆓 100% gratuit
🔓 Open source
🐍 Développé en Python
🛠️ Plusieurs outils réunis dans un seul programme
🤝 Projet créé par et pour la communauté
📚 Peut être utilisé pour apprendre et expérimenter
📥 Installation
1. Télécharger le projet

Clique sur Code → Download ZIP sur GitHub.

Décompresse ensuite le fichier .zip sur ton ordinateur.

2. Ouvrir le dossier

Entre dans le dossier du projet après l'avoir décompressé.

3. Installer le projet

Ouvre un terminal dans le dossier et lance :

python setup.py install

Si nécessaire, tu peux également installer les dépendances avec :

pip install -r requirements.txt
4. Lancer Multi Tools

Une fois l'installation terminée, lance le fichier principal du projet :

python main.py
